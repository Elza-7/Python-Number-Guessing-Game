# Number Guessing Game

A simple number guessing game built with Python while learning the basics.

## How it works

- The computer picks a secret number between 1 and 100.
- You guess the number, and the game tells you if it's too high or too low.
- You have a limited number of attempts to find it.
- When the game ends, it shows how many attempts you used.
- You can choose to play again or quit.

## How to run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository:
   ```
   git clone https://github.com/Elza-7/Python-Number-Guessing-Game.git
   ```
3. Open a terminal in the project folder and run:
   ```
   python game.py
   ```
